# Discord Trading Alert Bot — Description (400 chars max)

Discord bot that scans stocks for technical signals. Uses weighted consensus of RSI, MACD, Bollinger Bands, SuperTrend, Stochastic, Williams %R, EMA & ATR volatility to generate Buy/Sell signals with confidence ratings. Recaps for S&P 100, any index (e.g. S&P 500, DAX), or single ticker. Watchlist, news sentiment, backtest & walk-forward. Free data via yfinance. Educational use only.
